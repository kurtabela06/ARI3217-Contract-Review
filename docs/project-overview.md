# Contract Review Assistant

ARI3217 individual project, Task 29.

Purpose: highlight contract clauses for human lawyer review.
The system supports review; it does not provide legal advice.

Dataset: CUAD v1, The Atticus Project, from public SEC filings.
Dataset attribution: CC BY 4.0; contract licensing has separate caveats.

The supplied notebook is the baseline.
Data, contract text and trained artifacts are not committed.

Current status: project setup; baseline results not yet measured.
